# 📊 Mobile Sales Analysis Dashboard – Power BI

This is my first Power BI project where I explored data visualization, data modeling, and interactive dashboard design using a **dummy mobile sales dataset** created for learning and practice purposes.

## 🚀 Key Features

* KPI cards for **Total Sales, Total Quantity, Transactions, and Average Unit Price**
* Monthly trend analysis for **Total Quantity**
* **City-wise sales performance** using map visualization
* Brand comparison by:

  * Total sales
  * Units sold
* Sales distribution by **Payment Method**
* Customer behavior insights through **Customer Ratings analysis**
* Fully interactive **slicers for Month, Brand, and Payment Method**

## 🛠 Tools & Skills Used

* Power BI
* Power Query (data cleaning & transformation)
* Data Modeling
* DAX (basic measures)
* Interactive dashboard design

## 📂 Dataset

The dataset used in this project is a **dummy/sample dataset** and does not represent any real company. It was used solely for practicing data analysis and visualization techniques.

## 📈 What I Learned

* Building a complete dashboard from raw data
* Creating relationships between tables
* Writing basic DAX measures
* Designing user-friendly and dynamic reports
* Extracting meaningful insights from data

This project represents my first step into the world of data analytics and business intelligence. More advanced projects coming soon!
